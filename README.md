# Private Vitor Tools

Old-school Windows-style security console UI.

## Modules

**Recon**  
nmap, whois, dns, subdomain

**Exploit**  
msf, sqlmap, hydra, hashcat

**Stress**  
ddos, slowloris, udp

**Stealers**  
discord, roblox, crypto, browser, steam

**Post**  
mimikatz, empire, c2

**Sys**  
status, clear, github

## Usage

Open `index.html` in any browser (desktop or mobile).  
No build step. No dependencies.
